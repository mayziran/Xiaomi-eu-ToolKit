# Xiaomi.eu ToolKit

针对 **xiaomi.eu / HyperOS 国际版**的**部分优化**工具，**主要功能是处理 MiPush（小米推送）**。

- **只在 xiaomi.eu（EU）版上实测过**，国际版请自行测试
- **国行版**也可以用它查看 MiPush 的注册情况

---

## 下载安装

**本 App**：到 [Releases](https://github.com/mayziran/Xiaomi-eu-ToolKit/releases) 下 APK，装到手机上，首次打开时**允许 root 授权**。

**配套模块**（可选）：到
[Xiaomi-eu-ToolKit-Zygisk 的 Releases](https://github.com/mayziran/Xiaomi-eu-ToolKit-Zygisk/releases) 下 zip，
在 Magisk / KernelSU / APatch 里安装，**然后重启设备**。

> **大概率国际版 HyperOS 不需要它。**
> 目前模块只伪装**很小范围**的参数，是针对 **xiaomi.eu** 特殊 build 的适配；
> 以后会根据实际使用情况增加伪装范围。

---

## 使用前提

- **root**（Magisk / KernelSU / APatch 都行）
  —— 注册记录在系统应用 `com.xiaomi.xmsf` 的私有目录里，没 root 读不到
- 系统里有**国行版**的小米服务框架 `com.xiaomi.xmsf`（版本号以 **`-C`** 结尾）
  —— 国际版（`-G` 结尾）也能装、能诊断，但推送不会真正生效
- 主要用于 **HyperOS / MIUI 系** ROM
- 系统 **Android 10（API 29）** 或更高
- 「功能」页里的天气 / 下载管理开关，还需要在 **LSPosed** 里启用本模块

## 页面

底部三个页签：**总览 / 功能 / 诊断**。另有「机型伪装」和「应用详情」两个二级页。

### 总览

列出所有**和推送有关**的应用，每条显示应用名、包名、状态徽章、appId。

- 顶部搜索框按 **应用名 / 包名 / appId** 过滤
- 下面一排筛选：**全部 / 已注册 / 未注册 / 已注销 / 推送禁用**，标签后带当前数量
- 点任意一条进入详情

> 只列「和推送有关」的应用（注册表里有记录的、注销过的、被禁用的、以及集成了 MiPush 的），**不是把你手机里所有 App 都列一遍**。

### 应用详情

| 项目 | 说明 |
| --- | --- |
| appId | 框架分配给它的编号，有值说明注册表里有它 |
| 注册密钥 | 注册时一起下发的密钥。**有这个才算真正能收到推送** |
| 推送 | 有没有被框架禁用 |
| 支持 MiPush | 有没有正确集成 MiPush |
| 已安装 / 系统应用 / uid | 基本信息 |

底部还有一个「**机型伪装**」开关 —— 对**这一个 App** 启用品牌伪装，等同于在机型伪装页里打开它。
（没装 Zygisk 模块、或没有 root 时，这个开关是灰的。）

### 诊断

排查问题主要看这页：

- **官方服务框架**：是不是官方框架（系统应用身份 + 签名指纹）、版本、**版本类型（国区版 `-C` / 国际版 `-G`）**、声明不声明推送支持、能不能拿到 root
- **区域**：`mipush_region`、`mipush_country_code`，以及**框架自己认为推送能不能用**
- **操作**：三个按钮，见下方表格
- **统计**：各类数量
- **数据文件**：框架各个数据文件在不在、读不读得到

#### 三个操作按钮

| 按钮 | 做什么 | 注意 |
| --- | --- | --- |
| **一键改为国区（China / CN）** | 往服务框架写 `mipush_region=China`、`mipush_country_code=CN` | 写完要**重启设备或重启框架**才生效 |
| **强行停止服务框架** | 强制结束 `com.xiaomi.xmsf` 进程 | 安全，系统会重新拉起它，注册记录不会丢 |
| **清除数据与缓存** | 清空 `com.xiaomi.xmsf` 的**全部数据**（含注册表） | **危险**：所有 App 的 MiPush 注册都会丢失，需要逐个重新注册，你改过的区域设置也没了。有二次确认弹窗 |

### 功能

功能入口 + 通用设置：

| 项目 | 说明 |
| --- | --- |
| **机型伪装** | 点进去管理「哪些 App 要伪装机型」（见下一节） |
| **天气：国内数据源** | 打开后重启天气，天气改用国内数据源 |
| **下载管理：迅雷加速** | 打开后重启下载管理，设置里出现迅雷加速 |
| **隐藏系统应用** | 全局开关，所有应用列表通用（默认隐藏） |

> 天气和下载管理这两个开关走 LSPosed，所以**必须先在 LSPosed 里启用本模块**，否则开关是灰的。
> 如果某些目标应用没有勾进 LSPosed 作用域，页面会用红字提醒你 —— 不勾的话开关不会生效。

### 机型伪装

- 顶部说明卡显示**模块状态**（已安装 / 未安装 · 已开启 N 个应用）
- 搜索框按应用名 / 包名过滤
- 可按 **名称 / 更新时间 / 安装时间** 排序
- 每个应用一行一个开关：打开即把它写进模块配置，**重启该应用后生效**
- 已开启的应用**始终显示**（不会被「隐藏系统应用」藏掉，免得开完就找不到了）

> 打开开关只是写配置文件，真正生效要靠配套的 Zygisk 模块。
> 没装模块、或没 root 时，页面会用红字提示，开关不可用。

## 状态徽章说明

| 徽章 | 颜色 | 含义 | 该怎么做 |
| --- | --- | --- | --- |
| **已注册** | 绿 | 有 appId 也有注册密钥，正常 | 无需处理 |
| **已注册·缺密钥** | 黄 | 有 appId，但**密钥丢了** | 多半收不到推送：把该 App 杀掉重开，或强行停止服务框架后重试 |
| **未注册** | 红 | 集成了 MiPush，但注册表里没有它 | 打开该 App 保持前台一会儿；或让它重新注册 |
| **配置不全** | 黄 | 声明了 MiPush 服务但不符合规范 | App 自身的问题，一般无解 |
| **未集成** | 灰 | 这个 App 本来就不用小米推送 | 正常，忽略 |
| **已注销** | 灰 | 框架记录它主动注销过 | 打开该 App 会重新注册 |
| **推送禁用** | 橙 | 已注册，但推送被框架关掉了 | 去系统设置里打开该 App 的通知权限 |

> 「推送禁用」是**独立维度**，可能和「已注册」同时出现。

## 「收不到推送」怎么排查

1. **打开总览，找到那个 App**，看它的徽章：
   - **未注册** → 用「机型伪装」对它开启伪装（需装配套 Zygisk 模块），重启该 App 再看
   - **已注册·缺密钥** → 杀掉该 App 重开，或强行停止服务框架
   - **推送禁用** → 去系统设置打开它的通知权限
   - **已注册** 但就是收不到 → 看第 2 步
2. **打开诊断页**：
   - 「区域 → 框架推送」是不是**启用**？如果不是（显示「禁用（region 不是 China）」）：
     - 先点「**一键改为国区**」，然后**重启设备或重启框架**
     - 还是禁用 → 说明你的服务框架**本身就是非国区版本**，需要换 (见下一节)
   - 「官方服务框架 → 版本类型」是不是 **国际版 `-G`**？是的话往下看
3. **换国区版服务框架**

### 换成国区版服务框架

- **替换**：自行替换成**国行版**的小米服务框架（`com.xiaomi.xmsf`，版本号带 `-C-`）
  - 提示**签名不一致** → 用**核心破解（CorePatch）**关掉签名校验再覆盖安装
  - 或者自己找别的替换方法 —— **后果自负**
- **替换之后**：
  1. **清除框架数据**
  2. 等框架重启、生成 `mipush_region` / `mipush_country_code` 这俩区域文件
  3. 点「**一键改为国区（China / CN）**」
  4. 点「**强行停止服务框架**」，等它重启

回到诊断页点**刷新**，确认区域是 `China` / `CN`、框架推送是「启用」。

> ⚠️ **系统 OTA 可能把它覆盖回去**，升级后重新检查诊断页。

## 配套模块：Xiaomi-eu-ToolKit-Zygisk

[Xiaomi-eu-ToolKit-Zygisk](https://github.com/mayziran/Xiaomi-eu-ToolKit-Zygisk) 是配套的 **Zygisk 模块**。

**怎么用**：装好模块重启后，在本 App 的「**机型伪装**」页打开目标 App 的开关，然后**重启那个 App**。
排障：`logcat -s XiaomiEuToolKitZygisk`，命中会打印 `pkg=... spoofing BRAND -> Xiaomi`。

<details>
<summary>手动编辑配置文件（进阶，一般用 App 里的开关就行）</summary>

路径：`/data/adb/xiaomi_eu_toolkit_zygisk/apps.conf`，一行一个包名，
支持 `包名|进程名` 只匹配某个进程、`-包名` 表示排除。改完要让该 App 重启才生效。

## 常见问题

**Q：显示「已注册」，但还是收不到推送？**
A：先看**注册密钥**那一行，显示「无」就是「已注册·缺密钥」，注册信息不完整。
再确认诊断页的「框架推送」是不是「启用」，以及服务框架是不是国区版（`-C`）。

**Q：诊断页 `mipush_app_info` 显示「不存在」，坏了？**
A：不是。这个文件**按需创建** —— 没有任何 App 被注销或禁用过，它就不存在。

**Q：识别成「非官方框架」是什么意思？**
A：说明你系统的 `com.xiaomi.xmsf` 不是官方签名（比如被换成了 **MiPushFramework** 那类第三方框架）。
本 App 只适配**官方框架**，这种情况下它显示的注册信息**不准确**，只能参考。

**Q：改了区域，诊断页还是旧的？**
A：右上角有**刷新**按钮。区域改动要重启设备或重启框架才真正生效。

**Q：支持哪些机型？**
A：只要是 HyperOS / MIUI 且有官方 `com.xiaomi.xmsf` 的机型都行（Android 10 以上）。
第三方替换版框架的数据结构不一样，判定不准。

**Q：会破坏保修 / 影响系统更新吗？**
A：App 本身只是读数据；三个操作按钮里只有「清除数据与缓存」会真正动系统数据（有二次确认）。
root 本身的影响请自行评估。
